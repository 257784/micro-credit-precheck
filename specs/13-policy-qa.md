# 任务：DeepSeek 政策问答与回答效果检查

## 来源与目标

- 用户选择 DeepSeek API，要求把已有检索接入大模型，完成政策问答。
- 面向风控专员和客户经理，仅解释虚构政策，不执行审批。
- 完成后：页面选择产品提问，得到带原文引用的回答；信息不足和 API 失败有明确状态。

## 当前行为

- CLI 可召回 8 条，重排序可选；已有真实对比未体现净收益，默认纯向量。
- 本轮 context-k=6 是开发设定；尚无生成 API、页面或回答评测。
- 基线：57 条 Python、7 条 JavaScript 测试及前端构建通过。
- Agent 环境存在数值库 DLL 拒绝访问；真实模型和付费 API 需要本机联调。

## 期望行为

- 产品过滤 → 8 条召回 → 6 条上下文 → DeepSeek JSON → 校验引用 → 展示。
- 缺产品补问；无候选或未知文号不编造依据；输入指令不得修改职责。
- 回答要点带来源编号和可核对的原文，出处由后端映射。
- 超时、认证/限流、空内容、非法 JSON、伪造引用或原文不符时，保留候选，不展示草稿。
- 凭据只从后端环境变量读取，不读取现有 .env、不写前端/报告、不回显上游错误正文。
- 无写业务状态的工具，最终授信决定仍由人工流程完成。

## 本轮范围

- 新增问答模型、服务和 DeepSeek 适配器，接入 FastAPI、CLI 和政策问答页面。
- 允许修改 AGENTS、README、.env.example、数据契约、管理说明与相关测试；新增回答评测脚本。
- 保持语料、向量快照、业务接口及复核状态；不下载模型、不引入真实客户数据。
- 暂不：多轮记忆、联网、上传、自动审批、流式、生产鉴权和容量优化。
- 用户配置本地凭据后调用 DeepSeek；Agent 不读取凭据或自行发起付费调用。

## 验收

- 正常问答、缺上下文、无依据、伪造引用、超时、限流、JSON 错误、指令边界及页面状态测试。
- 评测保存逐题候选、回答、引用匹配和人工复核栏，不把引用合法当成语义正确。
- `python scripts/check_project.py`；本机页面和 CLI 验证真实 DeepSeek。
