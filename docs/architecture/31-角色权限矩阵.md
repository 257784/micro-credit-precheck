# 角色权限矩阵（教学系统）

本表记录用户确认的目标权限；数据范围和实现情况以备注为准。1 表示允许，0 表示不允许。所有申请数据均由服务端校验登录身份及数据范围。

| 功能 / 操作 | 企业客户 | 客户经理 | 风控专员 | 审批人员 | 管理员 |
|---|---:|---:|---:|---:|---:|
| 保存申请草稿、正式提交、补件后提交 | 1 | 0 | 0 | 0 | 0 |
| 查看申请列表和详情 | 1 | 1 | 1 | 1 | 0 |
| 手动认领、分配或绑定负责人 | 0 | 0 | 0 | 0 | 0 |
| 上传或补充材料 | 1 | 0 | 0 | 0 | 0 |
| 查看材料清单、正文和解析结果 | 1 | 1 | 1 | 1 | 0 |
| 运行材料完整性检查 | 1 | 0 | 0 | 0 | 0 |
| 查看材料完整性检查结果 | 1 | 1 | 1 | 1 | 0 |
| 查看工作台 | 0 | 1 | 1 | 1 | 0 |
| 查看风险看板 | 0 | 1 | 0 | 0 | 0 |
| 提出补件建议（不退回申请） | 0 | 1 | 0 | 0 | 0 |
| 正式要求补件并退回 | 0 | 0 | 1 | 0 | 0 |
| 运行并保存 AI 风险预审 | 0 | 0 | 1 | 0 | 0 |
| 查看 AI 预审报告及证据 | 0 | 1 | 1 | 1 | 0 |
| 开始、填写并提交人工复核，转交审批 | 0 | 0 | 1 | 0 | 0 |
| 查看人工复核记录及审批进度 | 0 | 1 | 1 | 1 | 0 |
| 作出并记录审批决定 | 0 | 0 | 0 | 1 | 0 |
| 使用政策问答及查看本人的会话 | 1 | 1 | 1 | 1 | 0 |
| 使用授信助手读取有权访问的申请、材料和已保存的检查结果 | 0 | 1 | 0 | 0 | 0 |
| 通过授信助手运行材料检查或风险预审 | 0 | 0 | 0 | 0 | 0 |
| 创建、停用账号及调整角色 | 0 | 0 | 0 | 0 | 1 |
| 查看助手工具调用审计 | 0 | 0 | 0 | 0 | 1 |
| 维护政策知识、材料规则或版本 | 0 | 0 | 0 | 0 | 1 |

企业仅能访问自己的申请；客户经理仅能访问系统分配给本人的申请；风控与审批人员分别限于服务端配置的可见状态。自动分配考虑启用的客户经理及其未结束申请数。客户经理不能因使用助手获得额外权限。审批人员查看工作台、材料检查和报告的权限，是为履行用户确认的审批职责采用的教学实现约定。

管理员维护政策知识、材料规则及版本的能力本轮明确暂不实现。审计由系统记录，助手无审计工具；当前通过管理员接口查看，尚无独立运维审计角色。正式生产环境的账号、权限和数据隔离仍需进一步安全加固。
