## 使用状态

本版为 2026-10-26 编写的 `1.0` 教学拟定稿。新增的必交材料、三个月收入期间、报价单替代等均为本轮明确编写的虚构规则，用于离线教学检索，不代表已经获得真实机构批准，也未修改 F2 运行规则。

离线演示应明确选用这套教学语料并保留“虚构教学”标识；上线业务规则前另行审核和接入。实际客户材料、代码、README、管理文件、旧 Mock 报告和验收答案均不属于本知识库正文。
