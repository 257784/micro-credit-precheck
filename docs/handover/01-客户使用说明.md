# 客户使用说明｜小微企业授信智能预审系统

适用对象：参加教学演示的企业客户、客户经理、风控专员和审批人员。系统仅用于虚构教学资料，不接收真实客户或征信数据。AI 输出是辅助线索，必须由人工核验；审批结果也仅为教学记录。

## 登录和角色

打开管理员提供的前端地址，本机默认是 `http://127.0.0.1:5173/`。使用本人教学账号登录；没有账号或不能登录时联系管理员，不要借用其他角色账号。可见申请和操作由服务端按角色与归属限制；申请不可访问时可能返回“申请不可访问”。

| 角色 | 可以做什么 | 不能做什么 |
|---|---|---|
| 企业客户 | 查看自己的申请、保存草稿、上传材料、检查并提交或补件 | 查看其他企业申请；代替风控或审批 |
| 客户经理 | 跟进分配给自己的申请、查看材料与报告、提出补件建议、使用授信助手 | 直接退回申请、运行风险预审或审批 |
| 风控专员 | 查看可复核申请、原始材料和报告，运行风险预审、记录复核或要求补件 | 以 AI 输出代替人工审批 |
| 审批人员 | 查看进入审批阶段的申请和复核材料，记录人工审批结果 | 把 AI 风险提示当作自动审批决定 |

## 企业客户：提交申请与补件

1. 进入“企业申请”，填写虚构企业名称、行业、地区、产品、金额和资金用途；涉及设备新旧或订单／合同依据时，按已知事实填写，不确定不要猜测。
2. 点击“保存申请草稿”，在“我的申请”选择该笔申请，上传对应类别的 PDF 或 DOCX。页面会显示解析状态；扫描件可能无法解析，需提供可读文本或联系工作人员。
3. 点击“运行材料完整性检查”，根据缺失项、异常项或待确认项补充。检查记录会标出是否因材料或声明变化而过期。
4. 点击“检查并正式提交”。系统会再次检查；只有通过当前初检才进入待风控复核。初检通过不代表材料真实充分，更不代表授信获批。
5. 若后续状态为“待企业补充材料”，查看反馈并补充、重新检查和提交。只有草稿或待补件状态可以继续上传材料。

“我的申请”仅列出本人申请。页面对部分常见手机号和身份证号做遮盖，但下载的是未脱敏原件；请只使用虚构教学文件。

## 客户经理：跟进申请和使用助手

在授信工作台查看系统自动分配给自己的申请，进入详情、材料和 AI 报告查看进度与证据。若发现需要补件，可在申请详情记录“补件建议”；该建议不会自行退回或修改申请状态，正式退回由风控处理。

授信助手可在授权范围内读取申请、材料清单和已有材料检查结果，并查询教学政策。没有有效检查结果或结果已过期时，应通知企业重新检查；不要将助手回答当成检查通过或审批决定。

## 风控专员：AI 预审和人工复核

1. 在工作台打开可复核申请，查看材料原件、解析情况和已有检查结果。
2. 在“AI预审与复核”运行风险预审，阅读报告中的证据、缺失信息和限制。报告为空、失败或证据不足时，不能视为无风险。
3. 开始复核后，对报告总体和每条关注项选择“采纳／部分采纳／不采纳”。逐项部分采纳或不采纳需要填写修改内容或原因；填写总体人工复核意见。
4. 资料可转审批时，选择“完成复核，转待审批”；需补充时选择“要求补件”，填写补件原因。报告或材料已变化时按提示刷新或重新运行预审。

人工复核结果是人工意见，不等同于最终授信或放款承诺。

## 审批人员：记录审批

进入可见的待审批申请，查看申请、材料、AI 报告和人工复核记录。在“审批处理”开始审批，填写审批意见后选择通过或未通过。系统记录操作人和结果；终态不能再次审批。教学审批不代表真实银行审批、额度或放款。

## 政策问答与 AI 边界

- 政策问答依据虚构教学知识库回答，应检查引用原文及适用条件；信息不足时补充事实，不确定时联系风控或客户经理。
- 不要求助手绕过规则、直接批准申请、给出最终授信结论，或根据没有证据的材料认定欺诈。
- AI 可能召回不相关条款、遗漏条件或引用校验失败。无依据、模型故障、输出为空或解析失败时，应查看提示并交由人工核实，而不是视为通过或无风险。
- 页面脱敏只覆盖部分常见格式；不要输入真实个人信息。政策问答流式输出和输入框不属于当前页面脱敏覆盖范围。

## 常见提示

| 提示或现象 | 用户处理 |
|---|---|
| 登录失败 | 核对账号和密码，联系管理员；不要反复猜测密码 |
| 检查显示缺失、异常或待确认 | 查看相应材料类别和说明，补充后重新检查 |
| 材料解析失败 | 核对文件是否为可读取的 PDF/DOCX，必要时联系工作人员 |
| 状态已变化、操作冲突 | 刷新申请后查看当前状态；不要反复提交 |
| AI 服务或政策检索不可用 | 暂停依赖该结果的判断，联系运维并人工核验资料 |
