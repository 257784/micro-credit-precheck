# 上线风险清单

当前结论：**仅可作为本机虚构数据教学原型；不建议用于真实客户数据或生产授信。** 以下是已知情况及后续工作，不表示已完成生产风险评估或取得上线批准。

| 风险 | 已知事实与可能影响 | 上线前需要完成 |
|---|---|---|
| 敏感数据脱敏不完整 | 带空格手机号等变体未被当前规则识别；姓名、银行卡号等不在当前覆盖范围，政策对话流式输出和输入框也未完全覆盖 | 明确数据分类、全链路处理和脱敏规则，进行样本验证和安全评审 |
| 原件未脱敏 | 已授权用户下载的是原始文件；页面掩码不改变文件或数据库内容 | 明确原件访问范围、查看及下载审计、存储加密和脱敏副本方案 |
| AI 解释或引用错误 | 检索可能遗漏条款，引用存在不保证语义正确；空结果或错误不能视为无风险 | 扩充评测、验证召回与引用、保留人工确认和降级路径 |
| 越权和身份安全 | 已有角色与归属校验，但现阶段是教学账号体系，尚未完成生产级身份、权限和安全加固 | 验证最小权限、身份生命周期、跨用户隔离、会话和安全配置；开展安全测试 |
| 状态并发 | 写入时使用行锁和状态校验，但尚无 MySQL 并发压力测试 | 针对重复提交、复核、审批和分配执行隔离 MySQL 并发测试与故障演练 |
| 审计不完整 | 部分未授权和网络层失败不在关键业务日志覆盖范围；日志缺少生产级防篡改和保留机制 | 明确审计范围、访问、留存、告警、完整性保护及集中存储 |
| 数据恢复 | 尚无自动备份和恢复演练；数据库、原件和索引分散存储 | 确定备份策略，验证一致性，在隔离环境完成恢复演练 |
| 部署与可用性 | 当前使用本机开发服务；单进程内存会话和登录限流不支持多实例 | 设计生产服务、监控、告警、负载、共享会话及扩缩容策略 |
| 验收覆盖 | 现有验收以隔离 SQLite、虚构样例和模拟依赖为主，未完成新机器全流程、浏览器人工验收及实际外部故障演练 | 补充真实部署环境的端到端、性能、故障恢复和用户验收；不得使用真实客户样例替代安全准备 |
| 业务规则与责任 | 教学政策虚构，AI、人工复核和审批的法律及机构责任不适用于真实授信 | 由业务、合规和技术负责人确认真实政策、人工审批权限及责任边界 |

当前验收中的三项具体问题及处理状态见 [验收测试报告](../acceptance-test-report-2026-11-10.md)。客户操作见 [使用说明](01-客户使用说明.md)，服务和恢复建议见 [运维交接手册](02-运维交接手册.md)。

## 建议处理优先级

优先级是本教学项目的交付建议，尚未经过真实机构的风险评级或上线审批。

| 优先级 | 风险及改进项 | 理由 |
|---|---|---|
| P0 | 敏感数据脱敏不完整、原件未脱敏 | 在允许真实客户数据进入前必须解决并验证 |
| P0 | 真实业务政策与人工审批责任未确认 | 当前政策和审批仅为教学模拟，不能直接用于真实授信 |
| P1 | 身份授权及跨用户隔离尚未完成生产级安全测试 | 需要完成最小权限验证和安全评审 |
| P1 | AI 召回、解释和引用的正确性未充分评测 | 错误线索可能影响人工判断，需扩展评测和保持人工复核 |
| P1 | 备份与恢复未演练，日志缺少完整性保护 | 数据丢失或争议发生时恢复和追溯能力不足 |
| P1 | MySQL 并发、实际依赖故障和部署环境未充分验证 | 需要隔离环境的并发、故障和部署演练 |
| P2 | 单进程会话、监控告警与多实例能力不足 | 正式部署或扩容前需完成架构与运维设计 |
